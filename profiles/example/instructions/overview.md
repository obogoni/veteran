# Playground - overview for Veteran

Playground is a Windows desktop app that links Azure DevOps work items to git worktrees and hosts AI coding agent terminals next to them.

Business areas a question will usually touch:

- **Workspaces and worktrees** - registering folders, discovering repositories and worktrees, creating and deleting worktrees (and when deletion is refused).
- **Tasks** - pinning Azure DevOps work items, the start-work flow, and how a worktree is linked to a task through its branch name.
- **Agents** - launching agent terminals and how each one is attributed to a worktree and task.

Answer in terms of what the user sees and can do in the app, never in terms of files or modules.
